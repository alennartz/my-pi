Understanding Node Streams

Node streams are one of the most misunderstood parts of the platform. They provide a way to process data incrementally instead of loading everything into memory at once.

A readable stream produces data, a writable stream consumes it, and transforms sit in the middle. Piping them together is the idiomatic way to build processing pipelines that stay fast under load.

Backpressure

Backpressure is the mechanism by which a slow consumer tells a fast producer to slow down. When write() returns false, the producer should wait for the drain event before writing more data.

import { createReadStream } from "node:fs";
const rs = createReadStream("big.txt");
rs.on("data", (chunk) => { if (!ws.write(chunk)) rs.pause(); });
