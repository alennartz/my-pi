A Page Hidden From Readability

This page keeps its entire content inside a container that Readability refuses, so the extraction must fall back to the DOM path. The fallback strips noise tags, selects the main region, and converts what remains into markdown. It contains enough words to pass the very-short threshold comfortably, because we need more than fifty words in the extracted output for the quality gate to avoid penalizing it as suspiciously thin content for the purposes of this particular fixture test.
